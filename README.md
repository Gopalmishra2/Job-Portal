# Job Portal

A simple and responsive **Job Portal Website** built using **HTML, CSS, and JavaScript**. This project provides a user-friendly interface where users can explore available job opportunities and interact with the job portal.

## 🚀 Features

* Responsive Job Portal UI
* Job listing section
* Search jobs functionality
* Job details display
* User-friendly navigation
* Clean and simple design
* Interactive functionality using JavaScript
* Responsive layout for desktop and mobile devices

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

```text
Job-Portal/

```

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Gopalmishra2/Job-Portal.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

You can also open the project directly in **Visual Studio Code** and use the Live Server extension.
